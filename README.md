# InOutData

Ветка: `main`. Состояние: `81dfbd1`.

## Назначение

Проект предназначен для представления тестовых данных и групп управляющих и статусных сигналов в C++. Базовая ветка фиксирует начальное состояние репозитория: здесь присутствует только `.gitignore`. Исходников, заголовков, примеров и правил сборки в этой ветке нет.

## Этапы разработки

| Ветка | Добавленные возможности |
| --- | --- |
| `1-create_InOutData320` | 320-битный контейнер, доступ по словам, байтам и битам |
| `2-create_InOutData128_112_8` | Контейнеры на 128, 112 и 8 полезных бит |
| `3-create_InOutSignals4_5_and_converters` | Группы InOutSignals4/5 и скалярные сигналы OTU4_CONVERTER |
| `4-create_InOutData64` | 64-битный контейнер, составные входные/выходные данные и дополнительные примеры |

Реализации следует изучать в соответствующих ветках: `main` не содержит объединённую последнюю версию библиотеки.
