# InOutData

Ветка: `1-create_InOutData320`. Состояние: `31bdddb`.

## Этап разработки

Первый рабочий этап: разработан контейнер `InOutData320` для представления 320-битной шины данных. Он позволяет обращаться к одному набору данных как к десяти 32-битным словам, сорока байтам или отдельным битам.

## Представление и интерфейс

В `include/InOutData320.hpp` объявлены `WIDTH=320`, `NUM_WORDS=10` и `NUM_BYTES=40`. Объединение содержит массивы `words`, `bytes` и именованные слова `w0`–`w9`.

Доступны:

- конструкторы из слов, массива байт и `std::vector<uint8_t>`;
- `get_word` / `set_word`, `get_byte` / `set_byte`, `get_bit` / `set_bit`;
- преобразования в массивы и векторы, загрузка из них;
- отдельные методы для little-endian и big-endian;
- текстовое представление, вывод и выбор формата через `OutputFormat`;
- условная совместимость с типами Verilator.

`InitOrder` задаёт порядок входных байт. Для передачи между компонентами следует явно выбирать нужный порядок и использовать методы преобразования, а не копировать весь объект через `sizeof`.

## Пример

```cpp
#include "InOutData320.hpp"

InOutData320 data;
data.clear();
data.set_word(0, 0x12345678u);
data.set_bit(10, false);
auto words = data.to_array();
auto bytes = data.to_vector_little_endian();
```

`main.cpp` создаёт объект из десяти слов, меняет бит 10, выводит данные и массив слов. Это демонстрация доступа к контейнеру.

## Структура

- `include/InOutData320.hpp` – публичный интерфейс.
- `src/InOutData320.cpp` – реализация.
- `include/Theme.hpp` – общие определения, идентификаторы и оформление вывода.
- `main.cpp`, `makefile` – демонстрация и сборка.

## Сборка и запуск

Нужны компилятор g++ с поддержкой C++17 и GNU Make. Команды выполняются в корне соответствующей ветки:

```sh
make
make run
make rebuild-release
make run-release
```

По умолчанию собирается `bin/otu4_datatype_test_debug`, release-версия – `bin/otu4_datatype_test`. `make clean` удаляет результаты сборки.
